WASD + drag mouse. The portal shows celestiary rendered by an iframe — but the iframe's draw calls themselves cross the wire (NetGL) and execute in the host canvas's GL context. Celestiary's renderer is substituted via a `window.__portalCreateRenderer` hook + a small shim in celestiary's bundle. No image bitmap round-trip.
