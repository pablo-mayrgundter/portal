Portal demos

Live 3D portals between independent browser worlds — the same two scenes wired across four different transports. WASD + drag mouse in each demo.

  • Local three
    Both scenes in one process. Per-pixel halfspace stencil + oblique near-plane clip; no transport.
  • Iframe (frame-RPC NetGL)
    Destination scene rendered in an iframe, ships color + packed-RGBA depth `ImageBitmap`s back over `postMessage`. Host composites via fullscreen quad with stencil + depth-clip.
  • Web Worker (frame-RPC NetGL)
    Destination scene in a `Worker` + `OffscreenCanvas`, no DOM. Same wire shape as the iframe path; different transport.
  • NetGL (command-stream)
    Destination's GL calls themselves cross the wire and execute in the host canvas's WebGL2 context. Composition is native: stencil + depth in one context, no bitmap round-trip.
